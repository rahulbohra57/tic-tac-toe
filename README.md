# Tic Tac Toe

**Play it live:** https://rahulbohra57.github.io/tic-tac-toe/

A classic two-player Tic Tac Toe game built with HTML, CSS, and vanilla JavaScript — playable directly in the browser with no setup required.

## Features

- Two-player gameplay (X and O take turns)
- Win and draw detection
- Winning cells highlighted
- Scoreboard that persists across rounds
- New Game and Reset Score buttons
- Clean dark UI with turn indicators

## How to Play

1. Open the live link above in any browser
2. Players take turns clicking cells to place X or O
3. First to get 3 in a row (horizontal, vertical, or diagonal) wins
4. Use **New Game** to reset the board, or **Reset Score** to clear the scoreboard

## Run Locally

```bash
git clone https://github.com/rahulbohra57/tic-tac-toe.git
cd tic-tac-toe
open index.html
```
